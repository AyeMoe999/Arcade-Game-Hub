# 🕹️ Arcade Game Hub & Suite

An interactive retro-style multi-game hub built in Python using **Pygame**. Launch and play multiple arcade games from a unified card-based launcher with custom theme support.

---

## 🎮 Included Games

- 🏓 **Arcade Pong**: Classic 2-player pong with smooth physics, particle effects, and customizable neon paddles.
- 👾 **Monster Battle**: Turn-based / tactical monster battle mini-game.
- 🎲 **Ludo**: Digital board game experience with custom board styling.

---

## ✨ Features

- **Central Arcade Launcher**: Sleek, card-based game selector with animated previews and smooth transitions.
- **Dynamic Theme Engine**: Switch between custom aesthetic visual themes on the fly:
  - 🌙 **Dark Neon** (Cyberpunk / Neon Arcade)
  - ☀️ **Clean Light** (Modern & Minimalist)
  - 🌆 **Retro Synthwave** (80s aesthetic)
- **Modular Architecture**: Independent game modules with clean state isolation.

---

## 🚀 Getting Started

### Prerequisites
Make sure you have Python 3.8+ installed.

### Installation
1. Clone this repository:
   ```bash
   git clone https://github.com/YOUR-USERNAME/Pong1.git
   cd Pong1
   ```

2. Install dependencies:
   ```bash
   pip install pygame
   ```

3. Run the arcade hub:
   ```bash
   python main.py
   ```
